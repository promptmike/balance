Balance

Each quadrant holds up to three terms. Solid marbles add within a term; translucent, weightless copies show multiplication as rows and depth. Each stack reads left to right. Scroll within a quadrant if a long stack extends beyond it. Drag marbles above or below either plate. Drop onto a stack to add to its sum, or into empty space to start a separate stack. Each quadrant multiplies its stacks. Each side divides the top by the bottom. An empty top counts as 0; an empty bottom counts as 1. Drag a marble back to the tray to remove it. Drag the padded background around a stack to move the whole stack to another quadrant.
